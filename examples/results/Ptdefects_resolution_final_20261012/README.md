# Verified k=32 decorated-surface comparison

This is the completed run of `decorated_resolution.py` on the 81,000-point decorated Pt(111) tutorial. It uses the original 40 descriptors and probe plane. The first tested k meeting the stated global/regional fidelity budgets and seed-agreement screen is 32.

The original silhouette and Davies–Bouldin optimum remains k=2. The k=32 comparison retains substantially more descriptor variation, but still merges fcc/hcp terrace sites and has some sensitivity to held-out refits. It is not a claim that the surface has 32 physically distinct site types.

[Short explanation](../../preview/Ptdefects/CLUSTER_RESOLUTION.md) · [Methods and reproduction](../../measurements/Ptdefects/resolution/README.md) · [Analysis code](../../experimental/decorated_resolution.py) · [Exact-site check](../../experimental/decorated_site_control.py).

## Contents

- `resolution_comparison.png` and `defect_zoom.png` compare k=2, k=10 and k=32 in physical coordinates.
- `resolution_curves.png` and `regional_fidelity.png` show compactness, descriptor fidelity and seed agreement.
- `resolution_trials.csv`, `resolution_summary.csv`, `channel_retention.csv` and `regional_retention.csv` contain the full sweep.
- `holdout_checks.csv` and `budget_sensitivity.csv` record refit and threshold sensitivity.
- `terrace_site_*.csv`, `terrace_sites_k*.csv` and `site_check_conditions.json` contain the exact-site control from the complementary diagnostic run.
- `plot_labels.npz` stores the three plotted label arrays (`k2`, `k10`, `k32`), each aligned with the tutorial's original descriptor-row order. Labels are arbitrary identifiers.
- `conditions.json`, `input_integrity.json` and `VERIFICATION.json` record run settings, input hash and end-to-end verification. The complementary checks were verified separately and are documented in the methods note.

The bulky input descriptor CSV is generated by the decorated tutorial and is not duplicated here. This directory is the sole retained exception to the Git ignore rule for generated example results. Reproduction commands should use a fresh output directory; keep this measured run as a reference.
