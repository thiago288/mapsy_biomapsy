# Experimental cluster resolution

This pilot compares descriptor coverage, seed stability, feature-noise sensitivity and known-site separation. It is separate from the main tutorial defaults. `cluster_resolution.py` reruns the descriptor study on a descriptor CSV generated by a tutorial; `site_checks.py` recomputes the Pt111 geometric/descriptor check.

The included measured tables cover eight full datasets, k=2,3,4,5,6,8,10,12,14,18,24,30; seeds42,371,829; K-means n_init5. Silhouette uses1500 fixed seeded rows; DB and coverage use all rows. Every standardized channel is scored for within-cluster variance explained. Equal family weighting divides features by sqrt(family size). The tables were measured on the surface-reference/radial-protein examples, not the classical probe planes.

Exact Pt111 descriptors distinguish atop, bridge, fcc and hcp. Original raw spectral k4 merges site types, while k10 separates the four nearest-grid site types in both tested seeds. Standardized K-means exact-site k8 separates four, but k10 merges hollows. Thus higher k need not preserve earlier distinctions. The physical check is only for ideal Pt111 at the revised probe height, radius4.5Å.

For proteins, the worst represented descriptor still has only about35–44% variance explained at k30 with ordinary standardization. This identifies unresolved information; it does not establish a correct number of biological environments. The illustrative coverage/ARI thresholds are not recommendations. Feature-noise tests are not atom perturbations. Avoid averaging per-descriptor preferred k as if correlated channels were independent votes.

Future work will evaluate rare-environment-aware coverage, independent physical constraints and nested refinement. No new validated cluster metric or physics-based graph algorithm is claimed here.

## Reproduce

```bash
python examples/experimental/cluster_resolution.py examples/results/YOUR_RUN/descriptors.csv --output examples/results/resolution_study
python examples/experimental/site_checks.py examples/results/YOUR_PT111_RUN/descriptors.csv --output examples/results/site_check --stability
```

Use fresh output folders. The site check requires the paired ideal Pt111 summary.json, radius4.5Å and48 atoms. `--stability` includes atomic perturbation, shifted queries, finer-grid refitting and periodic translation. Exact descriptors and nearest-grid cluster assignments are distinguished explicitly.

## Decorated Pt(111) fidelity comparison

`decorated_resolution.py` runs a three-seed sweep with explicit descriptor-fidelity budgets and a seed-agreement screen. `decorated_site_control.py` checks the four exact terrace-site families and recomputes a descriptor subset.
